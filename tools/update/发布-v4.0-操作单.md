# v4.0 发版操作单（主线 + 兼容版）

本版包含三个新功能：① 新学页「熟」标记（跳过拼写直接进复习）  
② 复习后可选「拼写全部 / 只拼写记错的」③ 笔记本（生词本小三角抽屉）。

---

## 一、主线包：CollocationMemory-4.0-release.apk（20.7 MB）

给所有正常设备的学生（Android 15+）。他们**不用你手动发**——  
清单已经推上去了（4.0 / versionCode 31 / minSdk 35 / sha 2985db9e…），  
只差你在 Gitee 建发行版，老用户打开 App 就会弹更新。

**步骤（和上次 v3.9 一样）：**

1. 浏览器打开 `https://gitee.com/bz360/collocation-update/releases/new`
2. **Tag 版本：`v4.0`**（一字不差！带小写 v，否则下载 404）
3. 标题：`v4.0`
4. 附件：选 `D:\AndroidProjects\CollocationMemory\tools\update\dist\CollocationMemory-4.0-release.apk`
5. 点「创建发行版」

建好后用你自己手机（现在是 3.9）走一遍：设置 → 检查更新 → 会弹 4.0 →  
下载 → 安装。这等于替全体学生先验了一遍。

> ⚠️ 3.9 的发行版留着别删（老链接还有人用），新建的 v4.0 与它并存即可。

## 二、兼容包：CollocationMemory-4.0-兼容版.apk（9.2 MB）

给**老设备**的学生（比如那台鸿蒙 4.2 的 MatePad）。这个包**不走发行版、不进清单**，  
只在群里单独发给需要的人。

**给她的原话（可直接复制）：**

> 不好意思，上次那个兼容版也要换一下，这次更新了几个功能：  
> ① 新学页右上角多了个「熟」—— 自己已经会了的词点一下，  
> 直接进复习，不用再拼写；  
> ② 复习完可以选「拼写全部」还是「只拼写记错的」；  
> ③ 生词本图标右上角多了个小三角，点开里面有个笔记本，  
> 学单词/复习时点卡片右上角的「记」就能把搭配收进本子里，  
> 本子里想写什么写什么，可以改可以删，只存在你平板本地。
>
> 操作：把之前下的旧安装包删掉，下载这个新文件直接覆盖安装就行  
> （学习记录都在）。注意先别点软件里弹出来的「更新」提示，  
> 以群里发的这个文件为准。

## 三、一个重要的新防线（本次已内置）

清单里现在登记了主线的 minSdk（35）。**从 4.0 起**，兼容包用户的 App  
发现系统装不上主线包时会**静默跳过整包更新弹窗**（词库热更新不受影响），  
再也不会出现「点了更新 → 下载 20MB → 解析包时出现问题」。

> 注意：这道防线在 4.0 里才生效。那台还在跑 3.9-兼容版的平板  
> 在升级到 4.0-兼容版**之前**仍可能看到一次装不上的更新提示 ——  
> 让她别点，直接装群里这个新文件就行。

## 四、以后每次发版的固定流程

1. 改代码 → `gradle assembleRelease`（主线包）→ `gradle assembleRelease -PlegacyCompat`（兼容包）
2. `python tools/update/make_manifest.py --apk <主线包> --changelog <说明.txt>` → 把 `tools/update/dist/` 推到 Gitee 仓库
3. Gitee 建发行版 `v<版本号>`，挂**主线包**
4. 兼容包手动发给老设备学生（不发发行版）
