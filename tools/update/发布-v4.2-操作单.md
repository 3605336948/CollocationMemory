# v4.2 发版操作单（单词朗读）

## 这次加了什么

| 功能 | 说明 |
|---|---|
| 自动朗读 | 新学/复习翻到一张卡片，自动念一遍英文（语速 0.85，略慢便于听清） |
| 顶栏「英」按钮 | 新学页、复习页顶栏各一个，点一下重听（样式与「熟」同款胶囊） |
| 设置开关 | 设置页「自动朗读」，关掉后卡片不出声，手动按钮仍可用 |
| 降级处理 | 设备没有英文语音数据时提示一次，不影响背单词 |

实现：`util/SpeechHelper.kt`（TTS 单例，Application 启动时预初始化）；
词条里的省略号占位（`take ... into account`）会读成 something。
