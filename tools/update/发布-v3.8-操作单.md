# v3.8 发版操作单（照这个敲就行）

仓库已建好：`https://gitee.com/bz360/collocation-update`（公开）
清单和词库文件我已经准备好并提交到本地仓库了，**只差推送和建发行版两步**。

---

## 第一步：把清单和词库推上去

打开终端（Git Bash 或 PowerShell 都行），逐条粘贴：

```bash
cd /d/AndroidProjects/CollocationMemory/tools/update/gitee-push
git push -u origin master
```

第一次推送时会弹出登录框，输入你的 **Gitee 用户名 `bz360`** 和 **Gitee 登录密码**。

> 如果提示密码错误，说明你的 Gitee 账号开了「私人令牌」保护：
> 去 Gitee → 头像 → 设置 → 安全设置 → 私人令牌 → 生成新令牌，
> 然后把令牌当密码填进登录框（用户名还是 `bz360`）。

推送成功的标志：终端显示 `master -> master`，没有报错。

**这一步推上去的东西**（3 个文件，共约 780 KB）：

```
manifest.json                  ← App 靠它知道有新版本
library/app_library.json       ← 词库热更新（新词、释义）
library/corrections.json       ← 释义订正表
```

> APK 不在这里推 —— 21 MB 的文件要放到「发行版」里，见第二步。

---

## 第二步：建发行版，把 APK 挂上去

浏览器打开：`https://gitee.com/bz360/collocation-update/releases/new`

按下面填（**Tag 和文件名必须一字不差**，写错了 App 就下不到）：

| 填写项 | 要填的内容 |
|---|---|
| 发行版标题 | `v3.8` |
| Tag 版本 | `v3.8` ← 必须正好是 `v` + `3.8` |
| 附件 | 选本地文件 `D:\AndroidProjects\CollocationMemory\tools\update\dist\CollocationMemory-3.8-release.apk` |
| 发行版介绍 | 把 `更新公告-v3.8.txt` 的内容贴进去（可随意，不影响 App） |

点「创建发行版」。

> 上传 20.7 MB 的附件可能要等一两分钟，别关页面。
> 如果提示超过大小限制：Gitee 单文件上限 100 MB，一般没问题；
> 真被限制了就改用「附件」→ 分片上传，或把 APK 放到夸克网盘再告诉我，我改下载地址。

---

## 第三步：验证有没有成功

两条命令，显示 `200` 就成了：

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://gitee.com/bz360/collocation-update/raw/master/manifest.json
curl -s -o /dev/null -w "%{http_code}\n" -L https://gitee.com/bz360/collocation-update/releases/download/v3.8/CollocationMemory-3.8-release.apk
```

（也可以直接在浏览器打开这两个链接。第一个应该显示一大段 JSON，
第二个应该开始下载 APK。Gitee 有时缓存 1~2 分钟，刚传完看到 404 就等一会儿再试。）

## 以后每次发版的精简流程

### 只更新词库（最快，用户无感）

```bash
cd /d/AndroidProjects/CollocationMemory
python tools/update/make_manifest.py          # 重新生成清单
cd tools/update/gitee-push
cp ../dist/manifest.json .
cp ../dist/library/*.json library/
git add -A && git commit -m "词库更新" && git push
```

### 更新 App 本体（改了代码/界面）

1. 改 `app/build.gradle.kts` 里的 `versionCode +1`、`versionName` 改新版本号
2. `gradle assembleRelease` 打包
3. `python tools/update/make_manifest.py --changelog tools/update/changelog-inapp-<版本>.txt`
4. 照上面第一步、第二步做一遍（发行版 tag 换成新版本号）

## 出问题了怎么办

| 现象 | 原因 / 处理 |
|---|---|
| `git push` 提示 Authentication failed | 用私人令牌当密码，见第一步的提示框 |
| 清单链接 404 | 还没推送成功，或 Gitee 缓存，等 1~2 分钟 |
| APK 链接 404 | 发行版 tag 不是 `v3.8`，或附件文件名不叫 `CollocationMemory-3.8-release.apk` |
| App 里点检查更新没反应 | 正常 —— 只有清单里的 `versionCode` 大于手机上的才会弹窗；当前手机装 3.8(29) 就查不到新版本，这恰恰说明链路通了 |
| App 弹「校验失败」 | APK 上传过程中损坏，重新上传一次 |
