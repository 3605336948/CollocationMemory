# v4.1 发版操作单（主线 + 兼容版）

本版是**修 bug 版**，没有新功能。修的是学生反馈的「切后台进度突然全没了」：

- 学习/复习/拼写会话原本只活在内存里，华为/鸿蒙切后台会直接杀进程，一杀整组消失；
  而且答过的词当场就排到了明天，所以重进 App 点「复习」只能拿到**下一批**，
  看着就像「刚才那组全不见了」。
- 现在会话（词表、第几张卡、拼到第几个词、记错名单）实时落盘，重启原样接回来；
  首页多了一条「继续上次的复习」，点一下就回到断掉的位置。

## 一、主线包：CollocationMemory-4.1-release.apk（20.8 MB）

给所有正常设备的学生（Android 15+）。**不用你手动发**——  
清单已经准备好了（4.1 / versionCode 32 / minSdk 35 / sha b783e5fd…2c6736），  
你只需要做下面两步：

### 第 1 步：在 Gitee 建发行版

1. 浏览器打开 `https://gitee.com/bz360/collocation-update/releases/new`
2. **Tag 版本：`v4.1`**（一字不差！带小写 v，写错就是 404）
3. 标题：`v4.1`
4. 附件：选 `D:\AndroidProjects\CollocationMemory\tools\update\dist\CollocationMemory-4.1-release.apk`
5. 点「创建发行版」

### 第 2 步：把清单推上去

**一定要等第 1 步做完再推**，否则先看到更新的人点下载会 404。

打开命令行（PowerShell 或 CMD），复制粘贴这一行回车：

```
cd /d D:\AndroidProjects\CollocationMemory\tools\update\gitee-push && git push
```

（提交我这边已经做好了：`021cc6d 更新清单 v4.1（app 4.1/32）`，
推送时会让你输 Gitee 账号密码/令牌。）

### 第 3 步：自己验一遍

用你自己的手机（现在是 4.0）走一遍：
设置 → 检查更新 → 会弹 4.1 → 下载 → 安装。
这等于替全体学生先验了一遍。

> ⚠️ 以前的发行版（v3.9 / v4.0）留着别删，老链接还有人用。

## 四、以后每次发版的固定流程

1. 改代码 → `gradle assembleRelease`（主线包）→ `gradle assembleRelease -PlegacyCompat`（兼容包）
2. `python tools/update/make_manifest.py --apk <主线包> --changelog <说明.txt>`
3. Gitee 建发行版 `v<版本号>`，挂**主线包**
4. 把 `tools/update/gitee-push/` 里的 manifest.json 更新并 push
5. 兼容包手动发给老设备学生（不发发行版）

> ⚠️ 顺序不能反：**先建发行版、再推清单**。
